# Talking Tuner

Play a string and the phone says which string it is and whether it is low or high. When the string comes in tune, the phone dings and says so.

How to use: open the page, tap Start, allow the microphone, and play a string. Keep the page open and the phone awake while tuning.

Guitar strings, low to high: E, A, D, G, B, high E. Tenor ukulele: G, C, E, A. Use the Guitar or Tenor ukulele button to switch.

Everything runs on the phone. Nothing is sent anywhere.
